# LFM

A simple file manager written in C++ using Qt 6.

## Features

- Browse files and directories
- Open folders
- Navigate to parent directory
- Open files using the default system application
- Choose directories using a file dialog

## Requirements

- C++17
- Qt 6 (Widgets)
- CMake

## Build

```bash
cmake -S . -B build
cmake --build build
```
or
```bash
chmod +x bar
```
and then use
```bash
./bar
```
 (BAR - Build And Run)

Run:

```bash
./build/LFM
```
